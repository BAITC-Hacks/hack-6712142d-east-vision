# Akim — городской симулятор

Интерфейс для текущего backend проекта HackAlem. React + Vite, белая, синяя и тёмная палитра, шрифты Golos Text и Manrope.

## Запуск фронтенда

```sh
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 5174
```

Сборка: `npm run build`. Backend запускается и настраивается отдельно участником команды, который за него отвечает.

## Подключение

По умолчанию используются `GET http://127.0.0.1:8000/api/data` и `POST http://127.0.0.1:8000/api/simulate`.

Другой адрес можно задать в `frontend/.env.local`:

```dotenv
VITE_API_URL=http://127.0.0.1:8000
```

После изменения переменной перезапустите Vite. Не помещайте OpenAI API key или другие секреты в VITE-переменные: они попадают в браузер. Для общения с сервером фронтенду ключи не нужны.

Если сервер недоступен, интерфейс показывает явный деморежим с локальной копией исходных данных. Выбор инициатив и карта доступны, запуск расчёта отключён. Нажмите «Подключить сервер» после запуска backend; успешное переподключение загружает свежие данные и начинает новый сценарий.

## Реализовано

- Обзор с интерактивной схемой районов и проверенными достопримечательностями.
- Визуальное отображение 14 инициатив, сравнение «Сейчас / С решениями».
- Фильтры, бюджет, выбор района каждой инициативы, ограничения и подсказки.
- Отправка пяти решений в формате `{ initiative_id, district }`.
- Экран результата: итоговый Score, изменения всех десяти показателей, сравнение районов, критические показатели, синергии, вклад мер, AI-анализ.
- При изменении решений предыдущий результат сбрасывается. Во время расчёта редактирование сценария блокируется.
- Плавные появления, числовые переходы и анимации карты. Настройка системы «уменьшить движение» отключает анимации.
- Адаптивная вёрстка, клавиатурная навигация, доступное окно справки.

## Файлы

- `src/App.jsx` — состояние приложения, страницы, интеграция.
- `src/api/api.js` — HTTP-запросы, таймауты, обработка ошибок.
- `src/Results.jsx` — результат строго из ответа backend.
- `src/CityMap.jsx` и `src/CityMap.css` — схема, миниатюры, визуальные изменения.
- `src/presentation.js` — подписи и проверки выбора на клиенте.
- `src/demoData.json` — демоданные, скопированные из текущего датасета проекта.
- `src/weights.json` — веса для отображения исходного индекса до расчёта; итоговый результат всегда приходит с backend.
- `src/styles.css` и `src/refinements.css` — оформление, адаптивность, анимации.

Backend и корневые файлы проекта в рамках дизайна не менялись. Для проверки на живом API требуется отдельно запущенный backend; при разработке он был недоступен на порту 8000.
