# akim. — интерфейс городского симулятора

React 18 + Vite. Визуальная основа в белой, синей и чёрной палитре.

## Запуск

```sh
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

Сборка: `npm run build`.

## Текущий режим

Фронтенд работает самостоятельно с демонстрационными данными из `src/data.js`. Обращений к серверу нет. Backend не изменялся. Отображаемый городской индекс — исходное значение из датасета, а не прогноз выбранного сценария.

Есть навигация, интерактивная условная схема районов, фильтрация инициатив, выбор района, добавление и удаление решений, бюджет, ограничения сценария и предпросмотр выбранных мер. Финальный расчёт и AI-анализ ожидают последующей интеграции.

## Основа для дальнейшей работы

- `src/App.jsx` — страницы и переиспользуемые компоненты Icon и CityMap.
- `src/data.js` — демонстрационные данные, категории и каталог.
- `src/styles.css` — визуальные стили, адаптивность и переменные палитры.

При интеграции заменить демонстрационные данные на `GET /api/data`; преобразовать решения `{ id, district }` в `{ initiative_id, district }` для `POST /api/simulate`. Итоговый Score брать только из ответа backend. Карта схематическая, не отражает реальные границы районов. Показатели направлений в карточке района — простые средние двух показателей для визуального обзора, не веса расчёта Score.
