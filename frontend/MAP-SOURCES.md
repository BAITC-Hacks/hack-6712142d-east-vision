# Ориентиры миниатюрной карты

Дата сверки открытых источников: 23 сентября 2026 года. Миниатюры — собственные стилизованные SVG-рисунки по характерным деталям объектов. Фотографии источников не включены в приложение.

Карта сохраняет пять условных районов из датасета хакатона. Она не воспроизводит актуальные административные границы и географические координаты объектов. В справочниках встречаются старые названия районов; ориентиры проверялись отдельно от формы схемы.

## Визуальный предпросмотр

CityMap получает уже выбранные меры через props `decisions`. Районные меры добавляют объект в конкретный район; городские — во все пять. Удаление решения убирает соответствующий объект. Переключатель «Сейчас / С решениями» управляет видимостью эффекта, не изменяя сценарий.

Все 14 инициатив имеют отображение: автобусная полоса, светофоры, ЛРТ, парк, чистое отопление, озеленение, школа, поликлиника, спортплощадка, фонари с камерой, переход, цифровой терминал, обновлённые сети, аварийная машина.

Объекты показывают тип выбранного мероприятия, а не масштаб строительства. До расчёта карта отображает исходные индексы; после успешного ответа /api/simulate режим «С решениями» показывает итоговые районные индексы сервера. Фронтенд подключён к существующему API; файлы backend не изменялись.
